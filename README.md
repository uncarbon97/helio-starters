# helium-starters

## 项目介绍

`helium-starters`是 Helium 脚手架及其业务微服务模块的基础支撑构件，可以快速引入其他中间件和基础配置

JDK compatibility: 25

[官方文档](https://helium.uncarbon.cc/)
[主要依赖](https://helium.uncarbon.cc/#/i18n/zh-CN/helium-starters/dependencies)
